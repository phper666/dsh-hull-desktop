# 空串是合法 key：根节点折叠被 falsy 判断静默跳过

| 项 | 内容 |
|:---|:-----|
| 背景 | 笔记目录树的「全部笔记」根节点（路径 = 空串 `''`）折叠按钮点击无反应，双击也无反应；子目录折叠正常。用户实测抓出，AI 探针因只测真实子目录而漏网两轮 |
| 决策或坑 | 树折叠逻辑用「路径字符串」做 key：`const p = chev.dataset.chev; if (p) { toggle(p) }` 与双击手势 `if (dir && dbl)`——根节点路径为空串被当假值，整个分支被静默跳过。修复：改「属性存在性」判别（`p !== undefined`）、去掉 `dir &&`（空串可比较、可作 Set 键）。**空串是合法域名（根），falsy 判断会把它吞掉** |
| 影响 | 功能静默失效且表面正常（按钮渲染、点击无报错）——最难查的一类 bug；e2e 若只覆盖非根节点则永久漏网 |
| 适用范围 | 所有以「路径/域名/前缀」为 key 的树形/层级结构（根节点常用 `''` 或 `.`）；React/Vue/vanilla 均适用；测试矩阵必须显式覆盖根节点 |
| 来源 | 出生：来源子需求 N2/N3 + 来源 PRD `2026-09-07-notes-prd.md`；引用：代码 `src/renderer/notes.js`（根节点分支）；提交 `b4f00dd`；e2e 场景「根节点折叠/展开」 |
| 引用 | 首次引用：目录树交互修复（2026-09-11）；后续复用 +1 |
