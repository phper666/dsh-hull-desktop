## 4. 模块概述

- 定位：开发者的笔记区——覆盖工作笔记（跟需求/ticket 走）与个人经验总结（跟人走）两类内容；纯 markdown 文件为事实源；兼作 dsh agent 可读的上下文（文件在磁盘上，Hull 零注入）
- 参与角色：单用户桌面应用，本机用户全权；dsh agent 为可选读取方（无集成）
- 子模块清单：笔记列表视图（树+列表+编辑器三栏）、任务关联（选择器/徽章/角标/相关笔记行）、存储与索引服务（主进程）、设置区块（存储目录）

## 5. 业务流程与状态机

- **笔记文件生命周期**：`新建（时间戳命名）→ 编辑（脏·未保存）→ 保存（原子写回盘）→ 删除（移 .trash/）→ 恢复 / 彻底删除`
  - 编辑中切走/关窗：脏状态提示（保存/放弃），不静默丢弃
  - 删除即移入回收站，TTL 30 天自动清理 + 容量上限（对齐 CON-R-skills-003 惯例）
- **任务关联状态**：`未关联 ↔ 已关联（task: 有效）`；`已关联 → 未知任务（ticketId 失效，徽章灰）→ 任务重建/重关联后回到已关联`
  - 关联/取消均通过点选操作回写 frontmatter，无手填 id
- **索引状态**：`启动全量扫描 → fs.watch 增量更新`；索引损坏/丢失可随时全量重建（索引非事实源）

## 6. 角色与权限矩阵

- 本机用户：全部操作（建/编/删/恢复/关联/改目录）
- dsh agent：通过文件系统直接读写笔记文件（用户自行操作，Hull 不参与、不注入）；Hull 侧视为「外部写入者」——fs.watch 感知后重建索引即可
- 无多角色/权限体系（单用户桌面应用，本模块不涉及）

## 7. 字段业务定义

| 字段 | 位置 | 语义 | 规则 |
|:-----|:-----|:-----|:-----|
| `task` | frontmatter | 关联的看板 ticketId | 值 = 看 boards.json 的 ticket id；可空；失效时 UI 降级不清洗字段 |
| `type` | frontmatter | 笔记类型徽章 | 自由文本（建议 工作/经验/想法），不枚举锁死；可空 |
| `tags` | frontmatter | 标签（v1 只存不解析成体系） | 自由文本；可空 |
| 文件名 | 磁盘 | 快速捕捉生成 `YYYY-MM-DD-<slug>.md`；手动重命名自由（重命名/移动 = 磁盘操作，索引跟随） | 同目录同名冲突 UI 拦截 |
| `notes.dir` | settings.json | 笔记根目录 | 默认 `<userData>/notes/`；可改任意本地文件夹；改路径不迁移旧文件（提示用户自行处理）；schema bump |

## 9. 枚举值与常量

- `type` 建议值：工作 / 经验 / 想法（自由文本，仅作 UI 徽章与过滤，不构成校验）
- 任务徽章态：`有效关联` / `未知任务（降级）` / `未关联`
- 回收站常量：TTL 30 天；容量上限 500MB（对齐 skills）
- 笔记文件扩展名：仅 `.md`

## 10. 第三方对接

- 无外部系统集成。唯一外部交互面 = 本地文件系统（用户/其他编辑器/Obsidian/dsh agent 可直接读写笔记文件，Hull 经 fs.watch 感知外部变更并更新索引）
- agent 读笔记为文件系统自然结果，非 Hull 功能（CON-R001/004：零注入）

## 12. 页面交互规范

- **笔记视图**（壳内 section，三区）：
  - 左：目录树（可折叠、子树计数、选中筛选）+ 搜索框（全局，提示「搜索为全局，不受目录筛选影响」）+ type 过滤徽章 + 笔记列表（updatedAt 倒序，项含标题/摘要/相对时间/type 徽章/任务徽章）
  - 右：编辑器（EasyMDE，编辑/分屏/预览三态；头部 frontmatter chips：type/task/相对路径；底部字数；脏标记；Cmd/Ctrl+S 保存）
  - 操作：新建（时间戳命名，继承当前目录）、移动到…（下拉选目录）、删除（入回收站）
- **任务选择器**：搜索框自动聚焦 + 候选平铺（`[看板] id 标题` + 相对时间），Enter 首个/Esc 关闭
- **看板侧**：任务卡片 `📝 N` 角标（点角标直达第一篇关联笔记；点卡片其他区域进详情）；任务详情「相关笔记：N 篇」行（点击跳笔记视图并筛选）
- 空态：无笔记（CTA 新建）/ 搜索无结果 / 目录为空
- 详细视觉以原型 `docs/prototype/2026-09-07-notes-prototype.html` v0.5 为准

## 13. 后端任务规范

本模块无服务端；主进程职责（等价「后端任务规范」）：

- **扫描/索引服务**：启动全量扫描 `notes.dir` → 内存索引（路径/标题/frontmatter/内容）；fs.watch 增量（外部写入者感知）；索引可全量重建
- **文件操作**：save（原子写：temp+rename，沿用 KanbanStore 约定）/ delete（移 .trash 并记录原路径+时间）/ restore / 彻底删除
- **回收站清理**：启动时 + 定时检查 TTL 30 天与容量上限（最旧先删）
- **设置接线**：notes.dir 读写 + settings schema bump；换目录重扫（不迁移）
- **IPC**：CON-R-notes-009 通道集，错误统一 toResult 包装

## 14. 端差异汇总

- 三端（mac/win/linux）功能一致；差异仅在路径（userData 由 Electron 提供）与 fs.watch 行为（win/linux 原生 watch，实现时按 CHOKIDAR/原生能力实测，异常降级为定时重扫）
- 无移动端/多端差异
