## 4. 模块概述

- 定位：开发者的笔记区——覆盖工作笔记（跟需求/ticket 走）与个人经验总结（跟人走）两类内容；纯 markdown 文件为事实源；兼作 dsh agent 可读的上下文（文件在磁盘上，Hull 零注入）
- 参与角色：单用户桌面应用，本机用户全权；dsh agent 为可选读取方（无集成）
- 子模块清单：笔记列表视图（树+列表+编辑器三栏）、任务关联（选择器/徽章/角标/相关笔记行）、存储与索引服务（主进程）、设置区块（存储目录 + **路径显示与复制按钮**，满足 agent 协同用户故事，v1.1 Q-075）

## 5. 业务流程与状态机

- **笔记文件生命周期**：`新建 → 编辑（自动保存 debounce ~2s）→ 保存（原子写回盘 + mtime 乐观锁）→ 删除（移 .trash/）→ 恢复 / 彻底删除`
  - 自动保存为主（v1.1 Q-069，业界笔记应用惯例）：失焦/关窗 flush、Cmd/Ctrl+S 显式强制；切换与关窗静默（autosave 已落盘）；仅保存冲突/失败走分流弹窗（改动三选/删除二选，见 CON-R-notes-002）
  - 删除即移入回收站，TTL/容量细则见 CON-R-notes-007
- **任务关联状态**：`未关联 ↔ 已关联（task: 有效）`；`已关联 → 未知任务（ticketId 失效，徽章灰）→ 任务重建/重关联后回到已关联`
  - 关联/取消均通过点选操作回写 frontmatter，无手填 id
- **索引状态**：`启动全量扫描 → fs.watch 增量更新`；索引损坏/丢失可随时全量重建（索引非事实源）

## 6. 角色与权限矩阵

- 本机用户：全部操作（建/编/删/恢复/关联/改目录）
- dsh agent：通过文件系统直接读写笔记文件（用户自行操作，Hull 不参与、不注入）；Hull 侧视为「外部写入者」——fs.watch 感知后重建索引即可
- 无多角色/权限体系（单用户桌面应用，本模块不涉及）

## 7. 字段业务定义

| 字段 | 位置 | 语义 | 规则 |
|:-----|:-----|:-----|:-----|
| `task` | frontmatter | 关联的看板 ticketId | 值 = 看 boards.json 的 ticket id；可空；失效时 UI 降级不清洗字段 |
| `type` | frontmatter | 笔记类型徽章 | 自由文本（建议 工作/经验/想法），不枚举锁死；可空 |
| `tags` | frontmatter | 标签（v1 只存不解析成体系） | 自由文本；可空 |
| `title` | frontmatter | 笔记显示标题（**单源**，v1.1 Q-062） | 自由文本；缺失回退文件名基名；改标题**不改文件名**（手动「重命名文件」为独立可选动作） |
| 文件名 | 磁盘 | 创建时 slug 生成（`YYYY-MM-DD-<slug>.md`，slug 空则时间戳序号）；**稳定不随标题自动变**（v1.1） | 同目录同名冲突 UI 拦截；手动重命名/移动 = 磁盘操作，索引跟随 |
| `notes.dir` | settings.json | 笔记根目录 | 默认 `<userData>/notes/`；可改任意本地文件夹；改路径不迁移旧文件（提示用户自行处理）；schema bump |

## 9. 枚举值与常量

- `type` 建议值：工作 / 经验 / 想法（自由文本，仅作 UI 徽章与过滤，不构成校验）
- 任务徽章态：`有效关联` / `未知任务（降级）` / `未关联`
- 回收站常量（v1.1 细则）：TTL 30 天（age=删除记录时间戳，≥ 即清）；容量上限 500MB（循环删最旧至达标）；检查=启动时 + 每 24h
- 自动保存：debounce ~2s；冲突副本命名 `xxx (冲突副本 YYYY-MM-DD).md`
- 索引降级重扫间隔：30s（watch 不可用时）
- 笔记文件扩展名：仅 `.md`

## 10. 第三方对接

- 无外部系统集成。唯一外部交互面 = 本地文件系统（用户/其他编辑器/Obsidian/dsh agent 可直接读写笔记文件，Hull 经 fs.watch 感知外部变更并更新索引）
- agent 读笔记为文件系统自然结果，非 Hull 功能（CON-R001/004：零注入）

## 12. 页面交互规范

- **笔记视图**（壳内 section，三区）：
  - 左：目录树（可折叠、子树计数、选中筛选）+ 搜索框（全局，提示「搜索为全局，不受目录筛选影响」）+ type 过滤徽章 + 笔记列表（updatedAt 倒序，项含标题/摘要/相对时间/type 徽章/任务徽章）
  - 右：编辑器（EasyMDE，编辑/分屏/预览三态；头部 chips：title（显示）/type/task/相对路径；自动保存 debounce ~2s + Cmd/Ctrl+S 强制；底部字数）
  - 操作：新建（继承当前目录）、「+ 新建目录」按钮、移动到…（下拉选目录）、删除（一次确认，文案注明可恢复）、回收站入口（底部含数量 → 内联视图：原路径/删除时间/体积 + 恢复/彻底删除）
- **任务选择器**：搜索框自动聚焦 + 候选平铺（`[看板] id 标题` + 相对时间），Enter 首个/Esc 关闭
- **看板侧**：任务卡片 `📝 N` 角标（点角标直达第一篇关联笔记；点卡片其他区域进详情）；任务详情「相关笔记：N 篇」行（点击跳笔记视图并筛选）
- 空态：无笔记（CTA 新建）/ 搜索无结果 / 目录为空
- 就绪态（v1.1 Q-070）：任务徽章/📝 角标在 boards/索引未就绪时中性占位（不标未知、角标不显示），就绪后统一刷新
- 视图边界（v1.1 Q-076）：默认视图仍 = 任务看板；upgrade 期间 notes 无额外门控；列表 chip/路径超长 ellipsis；win 路径统一 `/` 显示
- 详细视觉以原型 `docs/prototype/2026-09-07-notes-prototype.html` v0.5 为准

## 13. 后端任务规范

本模块无服务端；主进程职责（等价「后端任务规范」）：

- **扫描/索引服务**：启动全量扫描 `notes.dir`（跳过隐藏目录与 .trash，v1.1）→ 内存索引（路径/标题/frontmatter/内容）；frontmatter 解析失败=三键视为空、照常入索引（v1.1）；fs.watch 增量（首选 chokidar，v1.1）；索引可全量重建
- **watch 细节**（v1.1 Q-074）：降级（watch 不可用）定时重扫 30s；自写回声 1s 窗口静默吞掉；rename 按 delete+add 处理
- **文件操作**：save（原子写 temp+rename + **前置 mtime 乐观锁校验**，v1.1）/ delete（移 .trash 并记录原路径+时间）/ restore（**冲突返回错误码不覆盖**，v1.1）/ 彻底删除
- **回收站清理**（v1.1 细则）：age=删除记录时间戳、≥30 天即清、超限循环删最旧至 <500MB、启动时 + 每 24h
- **设置接线**：notes.dir 读写 + settings schema bump；换目录重扫（不迁移）+ 切换前置脏处理（v1.1）
