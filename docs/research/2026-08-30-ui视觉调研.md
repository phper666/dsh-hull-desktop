# 壳内 UI 视觉调研：现状盘点、同类基准与规范提案

> 飞书任务：`[Hull][UI调研] 检查器/壳 UI 视觉优化调研`（Backlog，2026-08-28 用户反馈「壳内 UI 不够好看」）
> 范围：Hull 壳内自有 UI——主导航/设置/升级/引导（shell.html）+ Skills 检查器（skills.css）+ 任务看板（kanban.css）。**不含 dsh 官方 Web UI**（官方领地，CON-R001）。
> 方法：代码级现状盘点（三个渲染文件全部视觉层）+ 同类工具基准调研（Linear / Raycast / Warp）。

## 一、现状盘点（代码级）

### 1.1 设计令牌现状

已有：21 个 `--hull-*` **颜色**变量，暗色默认 + 亮色 `[data-theme="light"]` 双套（CON-R-theme-002）。
缺失：**只有颜色令牌**——间距、字阶、圆角、阴影、动效全部硬编码散落（圆角 4/6/8/10/12px 五档并存，间距 4~20px 无栅格，字号 10~18px 九档无字阶）。

### 1.3 已有的好底子（保留不动）

颜色变量化 + 双主题骨架、骨架屏 shimmer、badge 语义色系（ok/warn/err/muted）、紧凑密度、ellipsis/title 细节、EasyMDE/markdown 暗色适配——这些是对的，规范在其上收敛而非推翻。

## 二、同类工具基准调研

### 2.1 Linear（任务管理，公认 dev-tool UI 标杆）

- **4px 基础栅格** + 刻意紧凑的间距（默认 gap ~5px）→ 密而不乱
- 标题**负字距**（大字号 -1~-3px letter-spacing）→ 压缩、自信的"快"感
- **单一低饱和紫 accent**，用于主操作与高亮，其余全是中性灰——状态色只在状态处出现
- 近黑分层表面 + 发丝边框；亮暗双主题均为一等公民（官方主题生成器）

### 2.2 Raycast（启动器，Compact Mode 流派）

- 三原则 fast / simple / delightful；Compact Mode 融合次要元素提密度
- 近黑蓝调底色（#07080a 级别）营造"macOS 原生应用"而非网页感；**4 级 surface ladder**（bg→surface→raised→overlay）
- **单一白色主 CTA** + 发丝边框 + 紧凑行；饱和色只留给扩展图标/插画
- Inter + GeistMono；hotkeys 外显（键盘优先的可视化）

### 2.3 Warp（终端，IDE 化流派）

- 块状命令 UI、键盘优先、motion tokens（微交互有明确的时长/缓动规范）
- 主题与 OS 亮暗同步

### 2.4 共性提炼（五条）

1. **单一强调色 + 中性灰基座**——语义色只出现在状态处，从不用作主按钮色之外的装饰
2. **4px 栅格 + 刻意的紧凑密度**——dev 工具的"专业感"来自密度控制而非留白
3. **表面阶梯（bg < surface < raised）+ 发丝边框**替代边框堆叠
4. **图标与标签配对**（16px stroke 图标），键盘快捷键外显
5. **120-200ms 微交互**：hover/press/focus 全部有反馈动画，快而轻

## 三、UI 规范提案（Hull Design Tokens v1）

### 3.1 色彩

- **收敛为单一强调色**：保留 `--hull-accent` #2e8bf5（与 dsh 官方 UI 的观感区分度好）；`--hull-primary` 全部归并到 accent（或 primary 重新定义为 accent 的 hover 深阶）。主按钮/active/focus/开关统一一个色
- **中性灰阶梯重排**（暗色）：bg #171c26 → panel #1e2430 → card #232b3a → hover #2a3342 四级表面；文字四级重排为 text #e8ecf3 / dim #b8c2d0 / muted #8b96a8 / sub #6b7688（修 note/sub 倒挂，sub 仅用于非关键脚注）
- 语义色（danger/success/warning/info/purple）**只用于徽标与状态反馈**，不作装饰

### 3.2 字阶与字体

- 五档字阶：11（徽标/脚注）/ **13（正文基准）** / 15（小标题）/ 17（页标题）/ 20（大标题）
- 标题 600~700 weight；数据/路径/命令统一 `--font-mono` 变量（消除 4 处内联重复）

### 3.3 间距与圆角

- 4px 栅格：4 / 8 / 12 / 16 / 20 / 24 六档
- 圆角三档：6（小按钮/徽标内件）/ 10（卡片/输入）/ 14（弹窗）

### 3.4 表面与阴影

- 表面三级：`--surface-0`（页面底）→ `--surface-1`（卡片/工具条）→ `--surface-2`（浮层/弹窗）
- 阴影两档：卡片 `0 1px 2px`；弹窗 `0 8px 24px`——用海拔替代部分 1px 边框

### 3.5 动效

- `--dur-fast: 120ms` / `--dur-med: 200ms`，统一 `cubic-bezier(0.25, 0.46, 0.45, 0.94)`（ease-out）
- 覆盖：按钮 hover/active、输入 focus、卡片 hover、弹窗进出（fade+scale 0.98→1）、toast
- 全部走 `prefers-reduced-motion` 守卫

### 3.6 图标

- 引入 16px stroke 图标集（建议 **lucide**，MIT、tree-shakable、风格与 Linear/Raycast 同源）
- 范围：nav 四项、工具条按钮、操作行（升级/取消/重新检查）、设置行首

## 四、优化方案（分阶段，纯视觉层，不动 JS 逻辑）

### P0 快赢（1 个 PR，纯 CSS，1~2 小时）

1. 双强调色收敛：`--hull-primary` 系全部指向 accent（或仅保留 hover 深阶）——一处变量改动全局生效
2. 暗色文字阶梯修正：note/muted/sub 重定义（消灭倒挂，sub 对比度提至 4.5:1）
3. 全局微动效：`button, .sbtn, .sk-btn, .kb-btn, .input, .sk-input, .kb-input { transition: background var(--dur-fast), border-color var(--dur-fast), color var(--dur-fast); }` + focus-visible ring
4. nav active 减重：accent 满底反白 → `accent-soft` 背景 + accent 文字 + 左侧 2px accent 指示条（Linear 式轻量 active）
5. 徽标/按钮 radius 统一三档

### P1 token 化重构（2~3 个 PR）

1. 新增间距/字阶/圆角/阴影/动效/mono 变量层，全文件替换硬编码值
2. 三套组件类合并：`.btn` 基类 + `--primary/--danger/--ghost` 修饰（sbtn/sk-btn/kb-btn 变为别名渐进迁移）；输入/弹窗/徽标同理
3. 亮色主题补全：硬编码 rgba 全部变量化

### P2 品牌个性（设计向，需出图）

1. logo/wordmark + nav 图标化；2. 空态插画（简单几何风即可）；3. hotkeys 外显；4. 密度模式（compact/comfortable）

## 五、落地与验证

- P0/P1 均为 CSS 层改造，**不触碰任何 JS 逻辑与 IPC**（本周期刚修完的渲染层逻辑零风险）
- 验证方式：每视图（nav/settings/升级卡/skills 列表+卡片/kanban 四视图/详情弹窗）亮暗两套截图走查 + 对比度抽查（WCAG AA）
- 建议节奏：P0 先落一版看观感，满意后 P1 跟进；P2 等品牌方向明确


## 附：开源 UI 库选型（P1 组件层的「借轮子」路线）

约束回顾：渲染层无构建（原生 HTML/CSS/JS）+ CSP self 全本地 vendor。据此排除 React/Vue + shadcn/Naive UI、Tailwind（需构建链=重写）、Bootstrap/Bulma（网页观感）。

| 层 | 选型 | 协议 | 无构建 | 说明 |
|:---|:-----|:-----|:------|:-----|
| 组件 | **Web Awesome v3**（Shoelace 正统续作，Font Awesome 团队） | Free 版 MIT（~70 组件） | ✅ script 标签 | dialog（焦点陷阱）/switch/select/toast/progress/skeleton 全内置——正好替换三套手写组件中行为最难写对的部分；主题走 CSS 变量与 --hull-* 同构；Pro 付费档不可再分发（不用即可） |
| 令牌 | **Open Props**（argyleink，活跃维护） | MIT | ✅ 纯 CSS 变量单文件 | 300+ 精调缓动/阴影/字阶/间距——P1 token 层可直接借用成熟值；颜色仍用自有品牌令牌 |
| 图标 | **lucide** | MIT | ✅ SVG 内联 | 16px stroke，Linear/Raycast 同风格 |
| 风格化候选 | **WebTUI**（2025-04，HN 热帖） | MIT | ✅ | 终端 TUI 美学——与「AI 编程工具壳」气质契合的个性路线，风格强自由度低，可做对比 demo 再定 |

推荐组合：P0 纯 CSS（见第四章）→ P1 vendor Web Awesome Free（先替 dialog/switch/toast/skeleton 四类行为组件）+ lucide 图标 + Open Props 缓动/阴影 token。代价：vendor +100~200KB JS（相对 452M app 可忽略）、shadow DOM 定制走 CSS parts（学习成本小）、标记结构 wa-* 化（渐进迁移）。

原型：docs/prototype/2026-08-30-ui-webawesome-prototype.html（CDN 加载版，对比手写 CSS 路线的观感与行为差异）。
