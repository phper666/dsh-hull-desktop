原型说明 · Skills 检查器（B2）

独立视图 壳内新增 nav 项「Skills 检查器」，统一扫描 agent 目录（claude-code / opencode / codex / gemini-cli / cursor / shared）聚合 skill 列表。 数据只读 agent 配置目录（~/.claude、~/.config/opencode、~/.agents…），**不触 DSH_HOME**（CON-R002 相容）。

全局 vs 平台：~/.agents/skills/ = 全局（universal）；~/.claude/skills/ = claude + opencode；~/.config/opencode/skills/ = opencode 专属。平台徽标显示该 skill 全部生效平台。

来源解析：metadata.source frontmatter → lock 文件 source+skillPath → 构建 GitHub URL，三级降级；均无显示「来源未知」且不可跳转。

升级检测：内容哈希（SHA-256，path+content 排序）对比远端（skills-lock.json / cc-switch content_hash / git tree SHA）；不一致显示可升级徽标。

  • 移除：点移除弹确认（显示物理路径 + 受影响平台，全局 skill 额外警示），确认后删除。
  • 升级：可升级 skill 显示琥珀徽标 + 升级按钮；确认弹窗显示来源与哈希变化；升级原子替换失败回滚。
  • 禁用/启用：每行开关切换生效状态；禁用后列表降透明度 + 「仅看已禁用」可筛出。
  • 来源跳转：点来源链接模拟 shell.openExternal 打开 GitHub。
  • 搜索 / 平台筛选 / 快捷开关：组合过滤即时生效；无结果显示空态。
